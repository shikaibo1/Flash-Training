# 数据目录

career_catalog.json 是 v2 初始目录：3个岗位、9个知识概念、15个行动原子、6个文字任务。内容为人工编写的教学起步示例，未经行业验证。原子定义包含动作、输入、交付、边界、三条量规、知识关联、先修关系、适用场景与版本。

默认库是 flash_training_v2.sqlite3。首次初始化从目录播种，不执行旧 JSON 导入。旧 atomic_skills.json 与 skill_library.json 已移除；旧数据库和个人历史不参与新版初始化，也不会被自动删除。

任务引用现有原子，原子引用知识和先修原子；先修关系必须无环。课程是知识概念的教学来源标签，不能证明行动能力。原子定义可跨场景复用，表现证据按场景区分。

修改种子不自动覆盖已初始化数据库。需要重新体验初始目录时，先停止服务，保留需要的数据，显式将 FLASH_DATABASE_PATH 指向一个新的数据库文件；不要隐式清空旧库。数据库、答案、证据和备份保存在本地，不提交 Git。
